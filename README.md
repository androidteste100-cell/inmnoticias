# Portal de Notícias em Astro

## Instalação
```bash
npm install
npm run dev
```

Abra `http://localhost:4321`.

## Onde editar
- Notícias: `src/data/noticias.ts`
- Cores e estilos globais: `src/styles/global.css`
- Anúncios: `src/components/AdSlot.astro`
- Cabeçalho: `src/components/Header.astro`

## Produção
```bash
npm run build
npm run preview
```

## Publicação
Envie o projeto ao GitHub e importe o repositório na Vercel, Netlify ou Cloudflare Pages. O comando de build é `npm run build` e a pasta de saída é `dist`.
